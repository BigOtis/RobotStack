# Robot Future Stack Setup - 15s Ad Production Prompt

## Style Block

- Mood: sharp, practical, capable
- Palette: background `#E7ECEF`, surface `#FFFFFF`, ink `#274C77`, accent `#6096BA`, support `#A3CEF1`
- Typography: display `Fraunces`, body `IBM Plex Sans`, labels `IBM Plex Mono`
- Motion: fast-forward engineering workflow, with continuous left-to-right progress

## Rhythm

`hook-PUNCH-build-CTA`

## Global Rules

- 15-second 16:9 ad
- Primary transition: push slide, `0.35s`, `power3.inOut`
- Accent transition: blur crossfade, `0.35s`, `power2.inOut`
- Use official Google Cloud / Cloud Run / MongoDB assets
- Use branded text chips for Codex and Claude Code where downloadable official image assets are not available
- Terminal motion is the narrative spine: prompt -> generated commands -> deploy -> live URL

## Scene 1 - Hook

### Concept

Open on the actual pain: the site exists, but deployment is still a maze. The frame should feel cramped for half a second, then snap into clarity.

### Depth Layers

- BG: blueprint grid, radial wash
- MG: headline, small clutter stack, Codex / Claude Code chips
- FG: terminal cursor, route rail

### Choreography

- Headline SLAMS in
- Clutter chips CASCADE
- Codex and Claude Code chips SNAP into alignment
- Cursor BLINKS and pulls the scene forward

## Scene 2 - Automation

### Concept

Show the skill behaving like an operator inside the coding workflow. The viewer should see commands appearing automatically while the stack assembles beside them.

### Depth Layers

- BG: route line, soft grid
- MG: terminal, official Google Cloud / MongoDB logos, Cloud Run icon
- FG: success ticks, command prompt, activity dots

### Choreography

- Terminal window SLIDES in
- Commands TYPE rapidly
- Logos ORBIT into their slots
- Cloud Run path DRAWS to a deploy badge

## Scene 3 - Cost + Scale

### Concept

Deliver the sharper value proposition: cheap hosting that can start small and scale when the idea works. The frame should feel like pressure releasing.

### Depth Layers

- BG: ghost text `START CHEAP / SCALE LATER`
- MG: Cloud Run card, scale rail, cost callout
- FG: traffic bars, route pulse

### Choreography

- `start cheap` STAMPS in
- Traffic bars GROW
- Scale rail EXPANDS
- Cost chip FLIPS from idle to active

## Scene 4 - CTA

### Concept

Resolve on the command and the outcome. The final frame should say one thing clearly: use the skill and ship the idea.

### Depth Layers

- BG: completed route
- MG: CTA line, command, live URL badge
- FG: logo strip, final pulse

### Choreography

- CTA RISES
- Command TYPES
- URL LOCKS
- Logo strip CASCADES
- Scene FADES cleanly at end

## Recurring Motifs

- Left-to-right route rail
- Terminal cursor
- Cloud stack assembling around the workflow
- Official stack logos acting as credibility anchors

## Negative Prompt

- No long explainer copy
- No overlapping panels
- No unsupported savings claims
- No static slide deck pacing
- No unofficial logo redraws
